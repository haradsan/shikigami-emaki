# 式神絵巻 — 花札百鬼祓い

**季節の札を打ち、式神と共に、一年をかけて百鬼夜行を祓え。**

花札の「役」で妖を祓っていく、スマホで遊べるローグライトです。
ブラウザで開くだけで動きます（インストール不要・外部ライブラリなし）。

▶ **遊ぶ: https://haradsan.github.io/shikigami-emaki/**

## あそびかた

- 一年十二か月＝十二の祓い。月ごとに現れる妖の「目標の霊力」に届けば祓い成功。
- 手札8枚から **1〜5枚** を選んで「打つ」。打った札で成立した**役がすべて重なり**、**霊力＝文×倍** が入る。
  打ちは4回、「流す」（捨てて引き直し）は3回まで。
- 札の文は **光20・種10・短冊5・カス1**。その月の札は「旬」で倍+2。
- 役:
  - 月の役 … 合わせ（同じ月2枚）・二つ合わせ・三本・三本合わせ・手四・**月流れ**（5か月続き）
  - 揃い … カス揃い・短冊揃い・種揃い（5枚すべて同じ種類）
  - 出来役 … 花見酒・月見酒・猪鹿蝶・赤短・青短・表菅原・三光・雨四光・四光・五光
- 祓いのあとは化け狸の**夜市**:
  - **式神**（5体まで連れて行ける仲間。左から順に力を発揮）
  - **呪符**（札を作り替える）・**詠み札**（百人一首の歌で役の段位を上げる）・**文箱**（福袋）
  - **神器**（季節にひとつ。剣・鏡・勾玉・宝珠・鈴の五つを集めると「五神器顕現」）
- 3・6・9月は季節の大妖、12月は百鬼夜行の主。妖はそれぞれ意地悪な「癖」を持つ。
- 絆のある式神（狛犬の阿吽・風神雷神・三猿）はそろうと化ける。
