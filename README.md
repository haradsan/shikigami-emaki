# ✦ 式神絵巻 ✦

**陰陽師となり、式神を従えて絵巻の盤上を巡る**——カードゲーム × ボードゲームの対戦ゲーム
（vs CPU／⚔三つ巴／🎮2人対戦）。カルドセプト系のオマージュ作品です。

## 世界観

古の絵巻に封じられた霊脈が、いま解き放たれる。
呪符より式神を呼び覚まし、霊地を結び、賽の導くままに盤上を巡れ。
⛩️鳥居をくぐり、🏯本宮へ凱旋した者こそ、当代随一の陰陽師。

## 起動方法

**`index.html` をブラウザで開くだけ**（インストール・通信不要、オフラインで動きます）。
スマホ・PCのどちらでも遊べます。進行はブラウザに自動保存されます。

## 遊び方の概要

- 🎲 賽を振って絵巻の盤面を移動（移動は進行方向へ。逆走はできず、分かれ道では行く手を選ぶ）
- 空き地に止まったら手札の**式神**を召喚して**霊地**を確保
- 敵の霊地では「通行料を支払う」か「式神で侵略バトル」
- 同じ属性（🔥火・🌳木・⛰️地・💧水）の霊地を集めると**連鎖**で通行料が倍増
- 自分の霊地はレベルアップで価値と通行料アップ。**式神の交代**も可能
- 隣接する自分の霊地が多いほど防衛式神が強くなる（**土地の援護** ST+10〜最大+40）
- ⛩️**鳥居**を規定数（多くのステージで3つ）くぐって🏯**本宮**を**通過または停止**すると
  周回ボーナス＝霊力＋自軍式神の全回復（劣勢時は霊力1.5倍の「逆転の風」）
- 🏯本宮に**ぴったり停止（または✨社還りの符）**すると、周回に関係なく
  **霊地の采配**＝支配する全霊地を対象に1回行動できる
- 1ターンの能動行動は1回。停止マスで行動しなかったターンは、通過した自分の霊地について
  **🏇侵攻・🔄交代・⬆レベルアップ**のどれか1つを行える（②通過アクション）
- **ステージごとの目標資産に達して🏯本宮に凱旋したら勝利！**（目標到達で⚑凱旋リーチ表示）。
  **霊力が尽きても敗北にはならない**——払いきれないときは持てる全てを渡して本宮へ帰還し、
  初期霊力で再スタート。勝つには相手を締め上げるだけでは足りず、**自分が凱旋するしかない**
- 呪術のカードは賽を振る前に手札をクリックで使用（1ターン1回）
- **⏱ 決着モード**: タイトルの「⏱ 決着」で**短期戦／標準／長期戦／大戦**を選べる

### マスの種類

🎴札（1枚ドロー）／💎霊力（+G）／⛩️鳥居（くぐるとボーナス）／🌀神隠し（対のマスへ移動）／
🌋火口（霊力を失う）／💨疾風（さらに2マス進む）／🎋おみくじ（大吉+300G〜凶-100G の運試し）／
♨️霊泉（自軍式神の全回復+60G）——そして始まりの地、🏯本宮。

### ステージ（全16面）

クリアすると次のステージが解放される。**盤面の形とマス数（16〜56）が全ステージで異なり**、
小さな環、細長い高地、橋や尾根の近道、2つの環が本宮で交差する「八の字」、星型の「四つ辻」、
三方から本宮へ道が流れ込む「円卓の三叉界」など。⏳第二巻の大型4面の先には、
👑**五帝**（各属性の頂点に立つ別格の式神）を従えるボスたちが待ち構える。
ステージごとに背景の色・通行料レート・CPUの性格・得意属性も異なる。

### バトル

- **属性相性**: 🔥火 → 🌳木 → ⛰️地 → 💧水 → 🔥火（左が右に強い・ST+10）
- 低確率で**💫会心の一撃**（ダメージ1.5倍）。格上にも一発逆転の目がある
- **戦闘後は残りHPのまま駐留**し傷が残る（周回・♨️霊泉で全回復）
- 特殊能力: **居合**（防衛でも先に攻撃）／**破魔**（土地HPボーナス無視）／**強襲**／**守護**／**豪運**／
  **捕縛**／**不動**／**護法**（敵の対象指定の呪術の対象にならない）／**連撃**／
  **物理無効**／**物理反射**／**呪力攻撃**（攻撃が呪力＝無効・反射を貫く）／**模倣**——ほか
  **成長・百鬼・遠隔・吸収・硬殻・背水・採掘・商魂・転生・天翔・看破・分裂**など多数
- **🏞 霊地に働きかける希少特性**: **築城**（防衛に勝つたびLv+1）／**焦土**／**破城**／**遁走**／
  **加勢**（隣の自領の式神を底上げ）／**霊力強奪**／**二形**（式神としても武具としても使える）

### カード（全336種・レア度つき）

- **第一巻**: 式神78種・宝具20種・呪術25種。各カードに★（並）〜★★★★（極）の**レア度**
- **⏳第二巻「時流の帖」（全213種）**: 🏛建造物・📜巻物・👑五帝を含む式神122種＋宝具32種＋呪術59種。
  テーマは**時間・成長・経済・連携**
- 代表的な呪術: ☄️**天火の符**（40ダメージ）・✨**大祓の符**（確実に消滅）・🌬️**神風の符**（強制移動）・
  ✨**社還りの符**（本宮へ帰還）・💫**雲隠れの符**（好きなマスへ）・🎲**倍賽の符**・❄️**金縛り**・
  💰**収奪の符**・🕯️**儀式**（手札1枚を捧げる大型呪術）・盤面エフェクト（霊力嵐・神域の加護など）
- **📚コレクション**: 勝利やクリアで**文箱**（カードの入った箱）を獲得。第一巻／第二巻の巻を選べる
- **♻️ポイント交換所**: 余剰カードを🎟文箱ポイントにして文箱を購入。10回ごとに未所持カード確定の「🌟救いの回」
- 🛠自分だけの30枚デッキを構築（プレイヤーごとに5つまで保存）
- **👤プレイヤー選択**: 最大5人が別々のコレクション・デッキ・進行度で遊べる

### モード

- **⚔ 三つ巴**: あなた＋ステージの主＋ランダムな乱入者の3人戦（勝てばカード7枚）
- **🎯 稽古**: 時短の練習対戦。勝てばカード3枚、🔥3連勝からは毎回稀以上1枚保証
- **🎁 封符戦**: その場で文箱10箱（計50枚）を開封し、出たカードだけでデッキを組んで1戦。
  コレクションの厚さに関係なく誰でも対等
- **🎮 2人対戦**: 同じ端末を交互に操作するホットシート対戦
- **🎪 週替わりの神事**: 毎週月曜に切り替わる特殊ルール（全7種）。ONで勝つとボーナスカード+2枚

### 見た目・音

- 全カードに影絵様式のアート、バトルはカットイン演出（⏩でスキップ可）
- 盤面は霊脈の道で結ばれ、ステージごとに彩りが変わる。文箱の開封は1枚ずつめくる演出
- **🎵 BGM**はファミコン風チップチューンを自動生成（場面ごとに6曲切替・オフライン動作・外部ファイル不要）
- 画面は**盤面の上に固定表示を重ねない**構成。👥情報窓／📜ログ／🗺マップ確認／🃏手札の
  表示切替で、スマホでも盤面が隠れない
